Token: Palavra ou símbolo que o modelo escolhe neste passo.
Probabilidade (P): Frequência com que o modelo seleciona este token dado o contexto anterior.
PCA 3D: Compressão matemática de 1.536 números para 3 eixos (X, Y, Z) para podermos ver o espaço semântico.
Cubo 3D: Mapa semântico onde ideias parecidas ficam juntas e as linhas mostram o fluxo do raciocínio.
Temperatura (T): Criatividade do modelo. Baixa (<0.5) repete o óbvio; alta (>1.0) arrisca caminhos diversos.
💡 Dica pedagógica: Observa como cada escolha de palavra altera a trajetória dentro do cubo.
